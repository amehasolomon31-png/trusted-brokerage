# 🏢 Trusted Brokerage Website

Trusted Brokerage በኢትዮጵያ ውስጥ በቤት፣ በመኪና እና በመሬት ድለላ ዘርፍ ፈጣን፣ ግልጽ እና ታማኝ አገልግሎት ለመስጠት የተቋቋመ ድርጅት የድረ-ገጽ ፕሮጀክት ነው።

## 🌟 ዋና ዋና ባህሪያት (Features)

- **የቤት እና መኪና ዝርዝሮች:** የተለያዩ ለሽያጭ እና ለኪራይ የቀረቡ ንብረቶች እይታ።
- **ቴሌግራም ኢንቴግሬሽን:** ተጠቃሚዎች ቀጥታ ወደ [@SozetsBot](https://t.me/SozetsBot) በመሄድ ዝርዝር መረጃ ማግኘት ይችላሉ።
- **Responsive Design:** በሞባይል፣ ታብሌት እና በኮምፒዩተር ስክሪን ላይ በሚገባቸው መንገድ የሚታይ።

## 🛠️ ጥቅም ላይ የዋሉ ቴክኖሎጂዎች (Tech Stack)

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Bot:** Node.js (SozetsBot)
- **Hosting:** Vercel / Netlify

## 📁 የፕሮጀክቱ ፋይሎች አደረጃጀት

- `index.html` - ዋናው መግቢያ ገጽ
- `cars.html` & `car-detail.html` - የመኪኖች ዝርዝር እና መረጃ
- `about.html` - ስለ ድርጅቱ
- `contact.html` - ማነጋገርያ ገጽ
- `dashboard.html` & `auth.html` - የተጠቃሚዎች ገጽ
- `dynamic.js` - የድረ-ገጹ እንቅስቃሴዎች እና ኢንተራክሽኖች
